## 2. 핵심 알고리즘 및 수학적 원리

### 2.1 가보르 패치(Gabor Patch) 생성 수학
가보르 함수는 가우스 정규분포 함수와 2차원 사인파 격자의 곱으로 정의되며, 인간의 대뇌 일차 시각피질(V1 영역) 뉴런의 수용야(Receptive Field) 반응과 일치합니다:

$$G(x, y; \theta, f, \sigma, \gamma) = \exp\left(-\frac{x'^2 + \gamma^2 y'^2}{2\sigma^2}\right) \cos\left(2\pi f x' + \psi\right)$$

- $x' = x \cos\theta + y \sin\theta$ (기울기 회전 좌표)
- $y' = -x \sin\theta + y \cos\theta$
- $\theta$: 줄무늬 각도 ($0^\circ, 45^\circ, 90^\circ, 135^\circ$ 등)
- $f$: 공간 주파수 (Spatial Frequency, 줄무늬 간격)
- **사용자 맞춤형 난이도**: 초보자도 쉽게 찾을 수 있도록 기본값을 `easy_2`(수평 $0^\circ$, 수직 $90^\circ$)와 최대 3줄 가보르 스트라이프로 최적화하였으며, 선택 시 실시간 방향 가이드라인을 제공합니다.

### 2.2 국제 표준 란돌트 고리(Landolt Ring) 시력 계산
국제 안과학회 표준 원리에 따라, 란돌트 고리의 틈새(Gap)가 눈에 이루는 시각(Visual Angle) $\alpha$ (분 단위, arcmin)와 시력(Decimal Acuity, $V$)의 관계:

$$V = \frac{1}{\alpha}$$

- 8방향(상, 하, 좌, 우, 북동, 북서, 남동, 남서) 무작위 틈새 제시
- 3연속 정답 시 난이도 상향(더 작은 고리), 오답 시 하향으로 0.1 ~ 2.0 시력 구간 정밀 측정

## 4. 로컬 스토리지 & 음성 피드백 엔진

1. **로컬 스토리지 데이터 키**:
   - `eye_training_preferences`: 야간 모드, 효과음 여부, 음성 가이드, 음성 페르소나(부드러운 코치/차분한 안과의사/활기찬 트레이너), 음성 속도, 진동 피드백
   - `eye_training_sessions`: 일일 훈련 완료 세션 기록(날짜, 시간, 점수, 모드)
   - `eye_training_acuity_records`: 시력 검사 날짜 및 측정 시력(좌/우/양안)
2. **Web Speech API & 오디오 합성 엔진**:
   - `speechSynthesis` 기반 자연스러운 한국어 음성 큐(시작 알림, 1분 경과 알림, 휴식 타이밍, 완료 축하)
   - `AudioContext` 기반 Web Audio API 신디사이저로 매칭 성공, 레벨업, 버튼 터치 효과음 오프라인 재생 지원
